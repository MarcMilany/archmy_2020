############# Справка по Gnome Disk Utility ##############
Справка:
https://apps.gnome.org/ru/DiskUtility/
https://github.com/GNOME/gnome-disk-utility
Синтаксис:
gnome-disks [ПАРАМЕТР…]
Параметры справки:
Параметр и Описание
-h, --help   # Показать параметры справки
--help-all   # Показать все параметры справки
--help-gapplication   # Показать параметры GApplication
--help-gtk  # Показать параметры GTK+
Параметры приложения:
Параметр и Описание
--block-device=DEVICE  # Выберите устройство
--format-device  # Форматировать выбранное устройство
--xid=ID   # Игнорируется, сохраняется для совместимости
--restore-disk-image=FILE  # Восстановить образ диска
--display=DISPLAY  # Используемый X-дисплей
