Расширения и полезные скрипты
https://github.com/cmus/cmus/wiki

Программы отображения статуса : программы, которые отображают текущую песню или используют эту информацию для выполнения других полезных действий.
Привязываемые скрипты : программы, которые должны выполняться из cmus и при необходимости могут быть привязаны к клавише.
Интерфейсы удаленного управления : Интерфейсы для удаленного управления cmus.
Темы : Цветовые темы для cmus
Отсоединяемый cmus : отсоединение cmus в фоновом режиме (режим «демона»)
cmus-auto-lyrics : отображение и загрузка текстов песен на основе Curses с автоматической прокруткой и поддержкой тегов.
cmus-lyrics : простой bash-скрипт, который извлекает текст текущей воспроизводимой песни.
lyvi : просмотрщик текстов песен, подключающийся к cmus и многим другим плеерам (используя libglyr)
cmus-sync : синхронизация мобильного устройства с плейлистом cmus.
cmus-mediakeys : Управление воспроизведением cmus с помощью глобальных медиаключей.
cmus-bundler : Сборщик плагинов и тем для cmus.
cmus-youtube : Патч, позволяющий загружать и воспроизводить песни с YouTube.
spotify-dl : позволяет загружать песни из Spotify. Их можно воспроизводить с помощью cmus.
Tidal-Media-Downloader : позволяет загружать песни с Tidal. Вы можете воспроизводить их с помощью cmus.
cmus-rpc-py : интеграция Discord Rich Presence для музыкального проигрывателя cmus.
spectroterm : Терминальный анализатор спектра на основе Curses для текущего воспроизводимого звука.
cmus-osx : управляет воспроизведением cmus с помощью клавиш мультимедиа и интегрирует OS Xцентр уведомлений в cmus.
cmusie : приложение macOS для управления воспроизведением cmus с помощью пользовательского интерфейса и/или клавиш мультимедиа.
cmus-dynamiclistfm : мини-расширение, которое генерирует плейлист на основе LastFmбазы данных.
Скрипты Gunqqer : Несколько музыкальных скриптов, в основном те, которые отображают обложки альбомов в терминале с помощью MPRIS.
Патчи к исходному коду cmus, которые не применяются, собраны здесь: Патчи сторонних разработчиков .
