fatresize — изменение размера тома FAT16/FAT32 без разрушения данных

СИНОПСИС
fatresize [ -s РАЗМЕР ] [устройство]

ОПИСАНИЕ
На этой странице руководства кратко описывается fatresize

Эта страница руководства была написана для дистрибутива Debian , поскольку исходная программа не имеет страницы руководства.

ПАРАМЕТРЫ
Эти программы следуют стандартному синтаксису командной строки GNU с длинными параметрами, начинающимися с двух дефисов (`-'). Ниже представлен список параметров. Полное описание см. в Info- файлах.

-h --help
Показать сводку опций.
-s --size
Изменить размер тома до SIZE[k|M|G|ki|Mi|Gi] байт или «max»

-i --info
Показать информацию об объеме
-p --progress 

Показать прогресс
-q --quiet 

Будь спокоен
-v --verbose
Подробный (не версия)

ПРИМЕРЫ
fatresize -s 2G /dev/evms/hdb2

fatresize -q -s max /dev/hde6

fatresize -i /dev/hdg3

Для запуска требуется размер и устройство. Вы можете изменить размер разделов, привязанных к устройствам, например, разделов EVMS.

ОШИБКИ
Вы не сможете изменить размер раздела FAT32 до размера меньше 512 МБ, поскольку Windows(R) некорректно работает с файловой системой FAT32 малого размера. Используйте FAT16.
