https://gcmd.github.io/ 
https://github.com/GNOME/gnome-commander

СИНОПСИС:
gnome-commander [-d СТРОКА] [опции] [опции gtk,gnome,bonobo]

ПАРАМЕТРЫ
--help
Показать сводку опций.
--version
Показать версию программы.
-l, --start-left-dir=СТРОКА
Укажите начальный каталог для левой панели.
-r, --start-right-dir=СТРОКА
Укажите начальный каталог для правой панели.
  --config-dir=СТРОКА
Укажите каталог для файлов конфигурации
-d, --debug=СТРОКА
Укажите используемые флаги отладки. Отладочный вывод будет записан в STDOUT.

Возможные флаги:
a: установить все флаги отладки
c: подсчёт файлов и каталогов
d: подсчёт ссылок на каталоги
f: подсчёт ссылок на файлы
g: отладка run_command
i: загрузчик изображений
k: пул каталогов
l: списки каталогов
m: отладка соединения
n: мониторинг каталогов
p: мониторинг скриптов
s: сетевой браузер SMB
t: теги метаданных
u: отладка действий пользователя
v: встроенный просмотрщик
w: поиск виджетов
x: xfer
y: краткая загрузка изображений на основе MIME
z: подробная загрузка изображений на основе MIME
[параметры gtk,gnome,bonobo]
Поддерживаются стандартные параметры gtk, gnome и bonobo. Используйте --help для просмотра возможных параметров.

ПРИМЕРЫ:
gnome-commander -d nvl
Запускает GNOME Commander с отладкой списков каталогов, внутренним просмотрщиком и средствами мониторинга каталогов.

ПАПКИ:
~/.config/gnome-commander/scripts
Пользовательские скрипты, используемые во всплывающем меню файлов.
/usr/lib/gnome-commander/plugins
Общесистемные плагины.
