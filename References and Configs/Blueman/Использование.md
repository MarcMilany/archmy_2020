Автозапуск
Должен быть создан следующий файл автозапуска: . Это означает, что Blueman должен автоматически запускаться в большинстве сред рабочего стола без ручного вмешательства. Подробнее об автозапуске /etc/xdg/autostart/blueman.desktopсм. в статье, соответствующей вашей среде рабочего стола или оконному менеджеру, а также в статье «Автозапуск» .

Разрешения
Чтобы получить файлы, не забудьте щелкнуть правой кнопкой мыши по значку Blueman в трее > Локальные службы > Передача > Получение файлов (Object Push) и поставить галочку в поле Принимать файлы с доверенных устройств .

Чтобы управлять устройствами, вам может потребоваться добавить пользователя в lp группу. В противном случае при подключении к устройству может возникнуть следующая ошибка: DBusFailedError: No such file or directory. Это связано с тем, что пользователь должен быть авторизован для связи с демоном Bluetooth через D-Bus — lp группа указана в /etc/dbus-1/system.d/bluetooth.conf. Сведения о добавлении пользователя в группу см. в разделе Пользователи и группы # Другие примеры управления пользователями .

Начиная с версии 2.0.6 официальная документация рекомендует создавать правила polkit , чтобы агенты polkit не запрашивали пароль при каждой загрузке. Для пользователя root добавьте следующие правила polkit:

/etc/polkit-1/rules.d/51-blueman.rules

/* Allow users in wheel group to use blueman feature requiring root without authentication */
polkit.addRule(function(action, subject) {
    if ((action.id == "org.blueman.network.setup" ||
         action.id == "org.blueman.dhcp.client" ||
         action.id == "org.blueman.rfkill.setstate" ||
         action.id == "org.blueman.pppd.pppconnect") &&
        subject.isInGroup("wheel")) {

        return polkit.Result.YES;
    }
});
