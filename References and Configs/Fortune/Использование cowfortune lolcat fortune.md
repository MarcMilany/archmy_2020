Использование cowfortune lolcat fortune
Использование cowfortune:
Для максимального эффекта поместите его в файл ~/.bashrc
Или, еще лучше, в стиле Linux Mint: пропишите в /etc/bashrc
Если это не поможет, проверьте $PATH и еще раз прочитайте раздел «Установка» ;)
- Добавить конфигурацию для каждого пользователя в ~/.config/cowfortune
  черный список - не выбирайте этих коров
  белый список — выберите только этих коров ('none', чтобы отключить cowfortune)
- Добавить общие параметры, такие как --help и --version
- Добавить некоторые варианты передачи ковсей и фортуны.

Чтобы указать, какие коровы вам нужны, вы можете создать для каждого пользователя белый или чёрный список файлов, которые будут учитываться. Также можно задать параметры, которые будут передаваться в функцию «Предсказание», например, указать файлы предсказания, их длину и т.д. Чтобы увидеть взрыв цвета с раком-богомолом, убедитесь, что у вас установлен lolcat .

Использование lolcat:
Также lolcat можно применять к абсолютно любому выводу в терминале, добавляя после введенной команды, прямой слеш "|" и саму команду "lolcat".
Пара примеров:
inxi -F | lolcat
df -Th | lolcat
cowsay "blah, blah, blah..." | lolcat
В общем думаю смысл понятен. Пользуйтесь.

Использование fortune:
Видишь, корову можно заменить на Такса, пингвина-талисмана Linux.
Какое отношение пингвин имеет к корове, я не знаю. Но я знаю, что можно использовать эту команду и получить пингвина.
fortune | cowsay -f tux

Чтобы отобразить случайную цитату при запуске интерактивного терминала, добавьте команду fortune в файл конфигурации rc предпочитаемой вами оболочки, например:
~/.bashrc
#!/bin/bash
fortune

Для русификации утилиты Fortune Mod в Arch Linux доступен пакет fortune-mod-ru — коллекция «сообщений дня» (фортунок или cookies) на русском языке для программы fortune. Чтобы установить пакет, нужно:
Установить зависимости: sudo pacman -S fortune-mod.
Скачать репозиторий с пакетом: git clone https://github.com/lexaone/fortune-mod-ru.git.
Перейти в директорию fortune-mod-ru, собрать инсталляционный файл: makepkg.
Установить получившийся пакет: sudo pacman -U ./fortune-mod-ru-1.54-1-any.pkg.tar.zst.
Важно: чтобы афоризмы отображались в терминале после каждого открытия, команду fortune нужно добавить в конец файла ~/.bashrc. Для этого нужно открыть и отредактировать файл, ввести в конец слово fortune и сохранить изменения (нажать клавиши Ctrl+S).
