### Краткое руководство Restic:
# После установки restic начните с создания репозитория для резервных копий:
# $ restic init --repo /tmp/backup
# и добавьте некоторые данные:
# $ restic --repo /tmp/backup backup ~/work
# Далее вы можете либо использовать restic restoreдля восстановления файлов, либо использовать restic mountдля монтирования репозитория через fuse и просмотра файлов из предыдущих снимков.
# Для получения дополнительной информации ознакомьтесь с онлайн-документацией:
# https://restic.readthedocs.io/en/latest/
### Чтобы начать работу с локальным репозиторием, сначала определите некоторые переменные среды:
# export RESTIC_REPOSITORY=/srv/restic-repo
# export RESTIC_PASSWORD=some-strong-password
# Инициализируйте репозиторий (только в первый раз):
# restic init
# Создайте свою первую резервную копию:
# restic backup ~/work
# Вы можете получить список всех созданных вами снимков с помощью:
# restic snapshots
# Вы можете восстановить резервную копию, записав нужный вам идентификатор снимка и выполнив команду:
# restic restore --target /tmp/restore-work your-snapshot-ID
# Рекомендуется периодически проверять метаданные вашего репозитория:
# restic check
# or full data:
# restic check --read-data
# Более подробную информацию читайте в следующих разделах.
# https://restic.readthedocs.io/en/latest/
