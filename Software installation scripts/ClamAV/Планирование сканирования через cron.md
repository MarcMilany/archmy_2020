Планирование сканирования через cron
Редактировать «crontab»
Запустите crontab -e редактирование crontab и добавьте следующую строку, отредактировав ее по своему усмотрению:

53 8 * * 5 /usr/bin/clamdscan --fdpass --multiscan --move="$HOME/.clam/quarantine" --log="$HOME/.clam/logs/$(date +\%Y\%m\%d)-weekly.log" "$HOME" 2>/dev/null 1>&2

Этот файл сканирует весь $HOME каталог каждую неделю по субботам в 08:53. man 5 crontab Подробнее о форматировании этого файла и man clamdscan пояснениях к используемым параметрам см. здесь.

Создать каталоги «логи» и «карантин»
Если каталоги 'logs'и еще не созданы, 'quarantine' их необходимо создать в $HOME каталоге:

mkdir -p " ${ HOME } /.clam/quarantine"  && mkdir -p " ${ HOME } /.clam/logs"
В противном случае, например, создание файла журнала может завершиться неудачей из-за отсутствия авторизации.

Установите ExcludePath для папки «карантин»
Чтобы исключить сканирование 'quarantine'папки в $HOMEкаталоге, добавьте 'ExcludePath'в нее '/etc/clamav/clamd.conf' с помощью предпочитаемого вами редактора, например, используя 'vim':

судо vim /etc/clamav/clamd.conf
Найдите ExcludePath и добавьте: ExcludePath ^/home/.*/\.clam/quarantine

Альтернатива: вы можете предоставить отдельный конфигурационный файл. Подробнее см. в разделах man clamdscan и man clamd.conf.

Планирование обновлений через cron
Служба автоматического обновления должна быть уже запущена, поэтому настройка обновлений через cronjob больше не требуется. Чтобы проверить службу, выполните:

systemctl status clamav-freshclam.service
Для конфигурации см man freshclam.conf. .

Если служба недоступна/не может быть запущена и включена в вашей системе: запустите , sudo crontab -e -u clamav чтобы настроить автоматические обновления. (Их следует запускать от имени clamav пользователя.) Добавьте следующую строку, чтобы обновлять их в 13:00 каждого часа:

13 * * * * /usr/bin/freshclam --quiet
