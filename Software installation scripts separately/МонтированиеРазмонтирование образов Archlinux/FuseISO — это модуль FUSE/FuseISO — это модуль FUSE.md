FuseISO — это модуль FUSE , позволяющий непривилегированным пользователям монтировать образы файловой системы ISO ( .iso , .nrg , .bin , .mdf и .img ).

https://wiki.archlinux.org/title/FuseISO


Установка
Установите пакет fuseiso .

Использование
Монтаж
Чтобы смонтировать образ:

$ каталог образов  fuseiso
Точка монтирования назначения должна быть доступна для записи и не иметь других смонтированных файлов или устройств.

Попробуйте fuseiso -hвсе доступные варианты.

Размонтирование
Чтобы размонтировать образ:

$ fusermount -u каталог
Эту команду можно использовать для отключения других устройств хранения данных, смонтированных другими инструментами монтирования.

Интеграция
Файлы GNOME
Для пользователей GNOME есть простой способ использования fuseiso из контекстного меню nautilus.

Сначала вам понадобится пакет actions-for-nautilus-git AUR , затем вам нужно сохранить следующие скрипты в папке по вашему выбору (например, ~/.local/bin/):

filemanager-actions-iso-mount.sh
#!/bin/sh

ФАЙЛ=$(базовое имя "$1")
MOUNTPOINT="$HOME/Desktop/$FILE"

fuseiso -p "$1" "$MOUNTPOINT"
файловый менеджер-действия-iso-umount.sh
#!/bin/sh

ФАЙЛ=$(базовое имя "$1")
MOUNTPOINT="$HOME/Desktop/$FILE"

fusermount -u "$MOUNTPOINT"
Сделайте их исполняемыми . Теперь запустите Actions for Nautilus .

Добавьте новое действие со следующими настройками:

На вкладке «Основные» :
Метка для команды: Монтировать ISO
Командная строка для выполнения: /path_to_scripts/filemanager-actions-iso-mount.sh %F
Текущий рабочий каталог: %d
На вкладке Шаблоны пути добавьте каждый из следующих шаблонов:
*.iso
*.nrg
*.bin
*.img
*.mdf
С помощью этого действия вы можете монтировать ISO-образы на рабочий стол. В ~/Desktop будет создана папка с именем образа. Команда fuseiso смонтирует образ в эту папку.

И второй:

На вкладке «Основные» :
Метка для команды: Размонтировать ISO
Командная строка для выполнения: /path_to_scripts/filemanager-actions-iso-umount.sh %F
Текущий рабочий каталог: %d
На вкладке Шаблоны пути добавьте каждый из следующих шаблонов:
*.iso
*.nrg
*.bin
*.img
*.mdf
Второе действие отмонтирует смонтированный образ ISO и удалит папку с рабочего стола.

Сохраните конфигурацию, затем перезапустите Nautilus с помощью команды nautilus -q в окне терминала.

Иногда для монтирования любого образа указанного типа приходится выходить из системы, просто щёлкнув правой кнопкой мыши по нему в папке «Файлы» и выбрав « Монтировать ISO» . Чтобы размонтировать образ, щёлкните правой кнопкой мыши по соответствующей папке на рабочем столе и выберите «Размонтировать ISO» .

Немо
Nemo как файловый браузер имеет пакетированную функцию по щелчку правой кнопкой мыши для монтирования iso с пакетом gnome-disk-utility . Размонтирование выполняется щелчком по соответствующему значку смонтированного iso, точно так же, как это делается для USB-накопителей.
